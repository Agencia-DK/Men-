# La Cornamenta · Cocina de Fuego

Menú digital interactivo para La Cornamenta, restaurante de cocina al fuego en Valle de Bravo.

## Sitio publicado

[https://agencia-dk.github.io/Men-/](https://agencia-dk.github.io/Men-/)

## Desarrollo local

```bash
pnpm install
pnpm exec vinext dev
```

El despliegue en GitHub Pages se actualiza automáticamente al enviar cambios a `master`.
